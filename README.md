# Random Password Generator 🔐

**Автор:** Данилина Александра

## Описание программы

Графическое приложение для генерации безопасных случайных паролей с возможностью настройки параметров и сохранением истории. Программа предоставляет интуитивно понятный интерфейс для создания надежных паролей любой сложности.

### Основные возможности:

- 🎲 **Генерация случайных паролей** - создание уникальных паролей с использованием random
- ⚙️ **Настройка параметров** - выбор длины и типов символов (буквы, цифры, спецсимволы)
- 📋 **Копирование в буфер** - быстрое копирование сгенерированных паролей
- 📜 **История паролей** - сохранение всех сгенерированных паролей
- 💾 **Персистентное хранение** - автоматическое сохранение истории в JSON файл
- 🎨 **Современный интерфейс** - удобный GUI с использованием Tkinter

## Требования

- Python 3.7 или выше
- Стандартные библиотеки Python (Tkinter, random, string, json, datetime)

###Использование
##Добавление тренировки
Заполните поля формы:

Дата - в формате ГГГГ-ММ-ДД (автоматически подставляется текущая дата)

Тип тренировки - например: Бег, Плавание, Силовая, Йога

Длительность - в минутах (целое или дробное число)

Нажмите кнопку "Добавить тренировку"

##Фильтрация записей
По типу тренировки:
Выберите тип из выпадающего списка

Будут показаны только тренировки выбранного типа

По дате:
Введите дату в формате ГГГГ-ММ-ДД

Нажмите "Применить фильтр"

##Сброс фильтров:
Нажмите "Сбросить фильтры" для отображения всех записей

##Управление записями
Удаление: Выберите запись в таблице и нажмите "Удалить выбранную тренировку" или клавишу Delete

Копирование: Дважды кликните по записи, чтобы скопировать информацию в буфер обмена

##Просмотр статистики
В нижней части окна отображается:

Общее количество тренировок

Общая длительность всех тренировок

Средняя длительность тренировки

Самый частый тип тренировки

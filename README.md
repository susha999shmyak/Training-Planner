# Random Password Generator 🔐

**Автор:** Данилина Александра

## Описание программы

Графическое приложение для генерации безопасных случайных паролей с возможностью настройки параметров и сохранением истории. Программа предоставляет интуитивно понятный интерфейс для создания надежных паролей любой сложности.

### Основные возможности:

- 🎲 **Генерация случайных паролей** - создание уникальных паролей с использованием random
- ⚙️ **Настройка параметров** - выбор длины и типов символов (буквы, цифры, спецсимволы)
- 📋 **Копирование в буфер** - быстрое копирование сгенерированных паролей
- 📜 **История паролей** - сохранение всех сгенерированных паролей
- 💾 **Персистентное хранение** - автоматическое сохранение истории в JSON файл
- 🎨 **Современный интерфейс** - удобный GUI с использованием Tkinter

## Требования

- Python 3.7 или выше
- Стандартные библиотеки Python (Tkinter, random, string, json, datetime)
